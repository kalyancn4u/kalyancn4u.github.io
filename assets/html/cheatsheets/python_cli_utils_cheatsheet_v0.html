tqdm — Progress Bars

Wrap any iterable to get a live progress bar.

1tqdm basicsv4.7
  • from tqdm import tqdm for x in tqdm(items): process(x)★
    Wrap the iterable — that's it. Shows rate, elapsed & ETA. Length is inferred from len().
  • from tqdm.auto import tqdm # notebook-aware★
    Use tqdm.auto — it renders a proper widget in Jupyter and a text bar in the terminal automatically.
  • tqdm(items, desc="Training", unit="batch", total=len(items))★
    desc = label, total needed when the iterable has no len() (generators).
  • from tqdm import trange for i in trange(1000): ...
    trange(n) == tqdm(range(n)).
2Manual, pandas, nestedbeyond loops
  • with tqdm(total=100) as pbar: pbar.update(10); pbar.set_postfix(loss=0.3)★
    Manual mode for non-loop progress; set_postfix shows live metrics next to the bar.
  • tqdm.pandas() df.progress_apply(fn) # instead of .apply★
    Progress bars for pandas apply/map/groupby after calling tqdm.pandas() once.
  • for i in tqdm(outer, desc="epoch"): for j in tqdm(inner, leave=False): ...
    Nested bars: leave=False so the inner bar clears each iteration.
  • total= for generatorsnote
    Without a knowable length there's no ETA/percentage — pass total= when wrapping a generator or streamed source.

click — Build CLIs

Decorate functions into command-line interfaces.

3Commands & optionsv8
  • import click @click.command() @click.option("--count", default=1, help="times") @click.argument("name") def hi(count, name): ...★
    Options (--flag) are named; arguments are positional. Decorated params map to function args.
  • click.echo(f"Hello {name}")★
    Use click.echo (not print) — handles encoding, color stripping when piped, and stderr.
  • if __name__ == "__main__": hi()★
    Call the command — click parses sys.argv, generates --help, and validates for you.
  • @click.option("-v", "--verbose", is_flag=True, count=True)
    is_flag = boolean switch; count=True for -vvv verbosity. multiple=True to accept repeats.
4Groups, prompts, typesreal CLIs
  • @click.group() def cli(): ... @cli.command() def build(): ...★
    Subcommands (git-style: tool build, tool deploy). Attach commands to a group.
  • @click.option("--env", type=click.Choice(["dev","prod"])) @click.option("--path", type=click.Path(exists=True))★
    Rich types validate input: Choice, Path, INT/FLOAT, File, DateTime.
  • @click.option("--pw", prompt=True, hide_input=True, confirmation_prompt=True)
    Interactive prompts. click.confirm("Sure?"), click.prompt("Name") for ad-hoc input.
  • with click.progressbar(items) as bar: ... · click.style("ok", fg="green")
    Built-in progress bar & colored output (or reach for rich).

rich — Beautiful Output

Color, tables, progress, and gorgeous tracebacks.

5print, console, tablesv15
  • from rich import print print("[bold red]Error[/] on [green]line 3[/]")★
    Drop-in print with BBCode-style markup for color/style. Also auto-pretty-prints dicts/lists.
  • from rich.console import Console console = Console(); console.print(obj); console.log("debug")★
    The Console is the full API. console.log adds timestamps & caller info; console.rule("Section") draws a divider.
  • from rich.table import Table t = Table("Name", "Score"); t.add_row("A", "9"); console.print(t)★
    Rich tables with borders, colors & alignment — far nicer than tabulate for interactive use.
  • from rich.markdown import Markdown · from rich.syntax import Syntax
    Render Markdown and syntax-highlighted code right in the terminal.
6Progress, tracebacks, inspectpower tools
  • from rich.progress import track for x in track(items, description="Working..."): ...★
    tqdm-style progress, rich-styled. Progress() for multiple concurrent bars with columns.
  • from rich.traceback import install install(show_locals=True)★
    Beautiful tracebacks with syntax highlighting & local variables — one line makes every error readable.
  • from rich import inspect inspect(obj, methods=True)★
    A rich alternative to dir()/help() — attributes, methods & docs in a nice panel.
  • from rich.live import Live · from rich.panel import Panel
    Live for continuously-updating displays (dashboards); Panel/Columns/Tree for layout.

tabulate — Quick Tables

One function, many formats — great for logs, READMEs & reports.

7tabulatev0.9
  • from tabulate import tabulate print(tabulate(rows, headers=["Name", "Score"]))★
    Takes a list of rows (or dict, or DataFrame) + headers → a formatted table string.
  • tabulate(df, headers="keys", tablefmt="github")★
    headers="keys" uses DataFrame/dict keys. tablefmt: github (Markdown), grid, pipe, plain, simple, html, latex, rst.
  • tabulate(rows, floatfmt=".2f", showindex=True, colalign=("left","right"))
    Number formatting, index column, per-column alignment.
  • # tabulate = static string output; rich.Table = live styled terminal
    When to use which: tabulate for text you'll paste into Markdown/logs; rich for interactive color.

PyYAML — Config Files

Read & write YAML — safely.

8PyYAMLv6
  • import yaml with open("config.yaml") as f: cfg = yaml.safe_load(f)★
    Always safe_load — parses YAML into plain dicts/lists. Returns a Python object you index like JSON.
  • yaml.safe_dump(data, f, default_flow_style=False, sort_keys=False)★
    Write YAML. default_flow_style=False = block style (readable); sort_keys=False keeps your order.
  • docs = list(yaml.safe_load_all(f)) # multiple --- documents
    Multi-document YAML (e.g. Kubernetes manifests) → a list.
  • NEVER yaml.load(untrusted) without a safe Loadersecurity
    Plain yaml.load can execute arbitrary Python. Use safe_load for any file you didn't write. (Modern PyYAML requires an explicit Loader= anyway.)
!Common gotchasread before shipping
  • yaml.safe_load, not yaml.load
    The one security must-know in this bundle — load on untrusted YAML is remote code execution.
  • tqdm needs total= for generators
    No length → no ETA/percentage. Also avoid printing inside the loop (it garbles the bar — use tqdm.write()).
  • click.echo over print
    Handles pipes/encoding/colors correctly; use err=True for stderr. Return codes via ctx.exit(1).
  • rich markup vs literal brackets
    [text] is parsed as markup. Escape a literal [ as \[, or pass markup=False.
  • tabulate float precision
    Defaults can show long floats; set floatfmt for clean numeric columns.
