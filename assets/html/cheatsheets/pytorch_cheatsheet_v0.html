Quick Reference · deep learning in Python · torch 2.13 (Jul 2026)

pytorch + torchvision · torchaudio

One idea holds the whole library together: a tensor remembers how it was made. That record is the autograd graph, and loss.backward() simply walks it backwards to fill in .grad. Layers, optimizers, data loaders and the two domain packages are all conveniences built around that single mechanism.

The loop everything serves  ·  and the three packages that feed it
# the whole library in twelve lines import torch, torch.nn as nn dev = torch.accelerator.current_accelerator() if torch.accelerator.is_available() else "cpu" model = nn.Sequential(nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 10)).to(dev) opt = torch.optim.AdamW(model.parameters(), lr=1e-3) lossf = nn.CrossEntropyLoss() # takes raw logits, not softmax model.train() for x, y in loader: x, y = x.to(dev), y.to(dev) loss = lossf(model(x), y) # forward: the graph is recorded here opt.zero_grad() # grads ACCUMULATE — clear them first loss.backward() # backward: the graph is walked and freed opt.step() # parameters move
Read this once and most of the reference below is just filling in the blanks.
PART I

torch  ·  the core

Tensors, autograd, layers, optimizers, data and the runtime. Nothing here needs torchvision or torchaudio installed.

01Install & verifyonce per env
  • pip install torch torchvision torchaudio★
    CPU-only default wheels on PyPI.
  • pip install torch --index-url https://download.pytorch.org/whl/cu128
    CUDA build. Pick the tag from the selector on pytorch.org.
  • torch.__version__
    Prints e.g. 2.13.0+cu128 — build tag included.
  • torch.cuda.is_available()
    Quick sanity check that the GPU build actually sees a device.
  • python -m torch.utils.collect_env
    Full environment dump — paste this into bug reports.
  • torch / torchvision / torchaudio versionspin
    The domain packages link against one exact torch build. Install all three together or you get import-time symbol errors.
02The import mapwhat lives where
  • import torch★
    Tensors, math, devices, save/load, compile.
  • import torch.nn as nn★
    Layer classes that hold parameters.
  • import torch.nn.functional as F
    The same ops as stateless functions.
  • import torch.optim as optim
    SGD, Adam, AdamW + LR schedulers.
  • from torch.utils.data import Dataset, DataLoader★
    The two halves of every input pipeline.
  • import torch.distributed as dist
    Multi-GPU / multi-node collectives.
  • from torchvision.transforms import v2
    Note the v2 — see card V2.
  • import torchaudio
    Waveforms, spectrograms, ASR pipelines.
03Create tensorsthe only data type
  • torch.tensor(data)★
    From a list or ndarray. Copies, and infers the dtype.
  • torch.zeros(2, 3) · ones · empty · full★
    Shape given as loose ints or a tuple.
  • torch.randn(2, 3) · rand · randint★
    randn is N(0,1); rand is uniform [0,1).
  • torch.arange(0, 10, 2) · linspace(0, 1, 5)
    Step-based vs count-based ranges.
  • torch.eye(3) · torch.from_numpy(arr)
    from_numpy shares memory with the ndarray.
  • torch.zeros_like(x) · randn_like(x)
    Copies shape, dtype and device from x.
  • x.clone()
    Deep copy that stays in the autograd graph. Add .detach() to leave it.
  • torch.manual_seed(0)
    Seeds all devices. Do it before you build the model.
04Attributes & dtypesread before you debug
  • x.shape · x.ndim · x.numel()★
    Dimensions, rank, total element count.
  • x.dtype · x.device · x.requires_grad★
    The three things wrong when a call fails.
  • x.to(torch.float32) · x.float() · x.long()
    Cast. .to() is a no-op if it already matches.
  • float32 · float16 · bfloat16
    Default is float32. bfloat16 keeps float32's exponent range — safer for training than float16.
  • int64 · bool · uint8
    Class labels must be int64; images arrive as uint8.
  • x.item()
    One-element tensor → Python number. Forces a device sync.
  • x.tolist() · x.numpy()
    .numpy() needs CPU and no grad: x.detach().cpu().numpy().
  • x.is_contiguous()
    False after permute/transpose — and then .view() raises.
05Shape surgerywhere most bugs live
  • x.view(2, -1)★
    Free re-interpretation. Needs contiguous memory; -1 is inferred.
  • x.reshape(2, -1)★
    Same result, but copies if it has to. Use this when unsure.
  • x.permute(2, 0, 1)
    Reorder all dims — e.g. HWC → CHW.
  • x.transpose(0, 1) · x.T
    Swap exactly two dims.
  • x.unsqueeze(0) · x.squeeze()
    Add / drop size-1 dims. unsqueeze(0) is how you fake a batch.
  • x.flatten(start_dim=1)
    Collapse everything after the batch dim — the CNN→Linear join.
  • torch.cat([a, b], dim=0)★
    Joins along an existing dim. Rank unchanged.
  • torch.stack([a, b], dim=0)★
    Creates a new dim. Rank +1. This is the pair people mix up.
  • x.expand(3, -1) · x.repeat(3, 1)
    expand is a free view; repeat allocates.
  • x.contiguous()
    The fix for "view size is not compatible…".
06Index, slice, reduceNumPy rules apply
  • x[0] · x[:, 1] · x[..., -1]★
    Basic slicing returns a view, not a copy.
  • x[x > 0]
    Boolean mask → flat 1-D tensor of the matches.
  • torch.where(cond, a, b)
    Elementwise pick — differentiable, unlike a Python if.
  • x.sum(dim=1) · mean · std · prod★
    Named dim disappears unless keepdim=True.
  • x.max(dim=1)
    Returns (values, indices) — a named tuple, not a bare tensor.
  • x.argmax(dim=1)★
    Logits → predicted class. The classification one-liner.
  • torch.topk(x, k=5) · sort · unique
    Top-5 accuracy, ranking, vocabulary building.
  • x.gather(1, idx) · x.scatter_(1, idx, v)
    Pick / write per-row by index. Trailing _ means in-place.
07Math & linear algebrathe actual compute
  • a + b · a * b · a ** 2★
    Elementwise, with NumPy broadcasting.
  • a @ b · torch.matmul(a, b)★
    Matrix multiply; batches over leading dims.
  • torch.einsum("bij,bjk->bik", a, b)
    Names every axis. Worth learning for attention code.
  • torch.bmm(a, b) · mv · dot · outer
    Explicit batch-matrix, matrix-vector, vector forms.
  • torch.exp · log · sqrt · abs · clamp
    clamp(min=, max=) is the standard gradient guard.
  • F.softmax(x, dim=-1) · F.log_softmax
    Always name the dim. log_softmax is the numerically stable one.
  • torch.linalg.norm · inv · svd · solve
    The modern namespace — the bare torch.svd spellings are legacy.
  • a.add_(b)in-place
    Trailing _ mutates. Autograd will raise if the value was needed for backward.
08Devices & precisioncuda · mps · xpu · cpu
  • torch.accelerator.current_accelerator()modern
    Device-agnostic: returns cuda / mps / xpu without an if-chain.
  • torch.accelerator.is_available()
    Guard the call above; falls back to "cpu".
  • x = x.to(dev) · model.to(dev)★
    Tensors return a copy; modules move in place. Don't write model = model.to() expecting otherwise.
  • with torch.autocast(dev, dtype=torch.bfloat16):★
    Mixed precision. Wrap the forward + loss only.
  • scaler = torch.GradScaler()
    Needed for float16, not for bfloat16.
  • torch.set_float32_matmul_precision("high")
    Enables TF32 matmuls on Ampere+. Near-free speedup.
  • x.to(dev, non_blocking=True)
    Async copy — only helps with pin_memory=True loaders.
  • torch.cuda.empty_cache()
    Returns cached blocks to the driver. Does not fix a real leak.
  • RuntimeError: expected all tensors on the same device
    The single most common runtime error. Move both the batch and the model.
09Autogradthe mechanism
  • x = torch.tensor(2., requires_grad=True)★
    Opt a leaf tensor into tracking. Model parameters do this for you.
  • loss.backward()★
    Accumulates d(loss)/d(param) into every .grad. Loss must be a scalar.
  • x.grad
    None until the first backward. Only leaves keep it.
  • with torch.no_grad():★
    Stop recording — for evaluation and manual parameter edits.
  • with torch.inference_mode():★
    Stricter and faster than no_grad. Prefer it for pure inference.
  • x.detach()
    Same data, cut out of the graph. The way to stop a gradient mid-network.
  • torch.autograd.grad(y, x)
    Returns grads instead of writing .grad — for higher-order tricks.
  • loss.backward(retain_graph=True)rare
    The graph is freed after backward. Only set this if you truly need a second pass — otherwise it silently leaks memory.
10nn.Moduleevery model is one
  • class Net(nn.Module):★
    Subclass, then define __init__ and forward. Never call forward() yourself — call model(x).
  • super().__init__()
    First line of __init__. Skip it and no parameter registers.
  • nn.Sequential(layer, layer, ...)★
    A model without a class, when the graph is a straight line.
  • nn.ModuleList([...]) · nn.ModuleDict
    Use these, not a plain Python list — a plain list hides the parameters.
  • nn.Parameter(torch.randn(3))
    A tensor attribute that counts as a trainable weight.
  • self.register_buffer("mask", t)
    Moves with .to() and saves in the state dict, but is not trained.
  • model.parameters() · model.named_parameters()★
    What you hand the optimizer.
  • sum(p.numel() for p in model.parameters())
    Parameter count in one line.
  • model.apply(init_fn) · nn.init.kaiming_normal_
    Custom weight init, applied recursively.
11Layersnn.* building blocks
  • nn.Linear(in_f, out_f)★
    Acts on the last dim only; leading dims pass through.
  • nn.Conv2d(in_ch, out_ch, k, stride, padding)★
    Expects (N, C, H, W). padding="same" preserves size at stride 1.
  • nn.MaxPool2d(2) · nn.AdaptiveAvgPool2d(1)
    The adaptive one fixes the output size for any input — how CNNs reach a Linear head.
  • nn.BatchNorm2d(ch) · nn.LayerNorm(shape)★
    BatchNorm across the batch (CNNs); LayerNorm within a sample (transformers).
  • nn.Dropout(p=0.5)
    Active in train(), a no-op in eval().
  • nn.Embedding(num_emb, dim)
    Integer ids → vectors. A lookup, not a matmul.
  • nn.MultiheadAttention(dim, heads)
    Pass batch_first=True unless you like (L, N, E).
  • nn.TransformerEncoderLayer · LSTM · GRU
    RNNs return (output, hidden), not a bare tensor.
  • F.scaled_dot_product_attention(q, k, v)fast
    Fused attention kernel. torch.nn.attention.flex_attention handles custom masks — and as of 2.13 runs on Apple Silicon too.
12Losses & activationspick by task
  • nn.CrossEntropyLoss()★
    Multi-class. Takes raw logits and int64 targets — softmax is built in.
  • nn.BCEWithLogitsLoss()★
    Binary / multi-label. Also takes logits, and is stabler than Sigmoid + BCELoss.
  • nn.MSELoss() · nn.L1Loss() · SmoothL1Loss★
    Regression. Smooth L1 (Huber) resists outliers.
  • nn.NLLLoss() · KLDivLoss · CTCLoss
    NLLLoss expects log_softmax output; CTCLoss is the speech/OCR one.
  • loss_fn(pred, y, reduction="none")
    Per-sample losses — needed for weighting and focal variants.
  • nn.ReLU() · GELU · SiLU · LeakyReLU★
    GELU/SiLU are the transformer defaults; ReLU still fine for CNNs.
  • nn.Sigmoid() · Tanh · Softmax(dim=-1)
    For reading probabilities at inference — not before a logits-based loss.
  • nn.Softmax() → nn.CrossEntropyLoss()wrong
    Double softmax. Trains, converges badly, and nothing warns you.
13Optimizers & schedulestorch.optim
  • opt = optim.AdamW(model.parameters(), lr=1e-3)★
    The sane default. Decouples weight decay properly — prefer it to Adam.
  • optim.SGD(params, lr=0.1, momentum=0.9)
    Still the best final accuracy for vision, with a schedule.
  • opt.zero_grad(set_to_none=True)★
    Default since 2.0 — frees memory as well as clearing.
  • opt.step()★
    Applies whatever is in .grad right now.
  • opt = optim.AdamW([{"params": a, "lr": 1e-4}, ...])
    Param groups: different LR for backbone vs head.
  • nn.utils.clip_grad_norm_(params, 1.0)
    Between backward() and step(). Standard for RNNs and LLMs.
  • optim.lr_scheduler.CosineAnnealingLR(opt, T_max)
    The common modern decay.
  • OneCycleLR · StepLR · ReduceLROnPlateau
    ReduceLROnPlateau is the only one whose step() takes a metric.
  • sched.step()order
    Call it after opt.step(), once per epoch (or per batch for OneCycle) — never before.
14Dataset & DataLoadertorch.utils.data
  • class DS(Dataset): __len__, __getitem__★
    Those two methods are the entire contract. Return one sample, not a batch.
  • TensorDataset(X, y)
    Wraps tensors you already have in memory.
  • DataLoader(ds, batch_size=32, shuffle=True)★
    Shuffle the train split; never the validation split.
  • num_workers=4, pin_memory=True★
    The two flags that usually fix a GPU-starved loop.
  • persistent_workers=True, prefetch_factor=2
    Avoids re-spawning workers every epoch.
  • drop_last=True
    Drops the ragged final batch — matters for BatchNorm.
  • collate_fn=my_fn
    Custom batching: padding variable-length text or audio.
  • random_split(ds, [0.8, 0.2]) · Subset · ConcatDataset
    Splitting and combining without touching disk.
  • WeightedRandomSampler(w, n)
    Class imbalance. Mutually exclusive with shuffle=True.
15The training loopno framework required
  • model.train()★
    Turns Dropout on and BatchNorm into batch-statistics mode. It does not enable gradients.
  • for x, y in loader:
    The DataLoader is a plain iterable; one pass = one epoch.
  • pred = model(x); loss = loss_fn(pred, y)★
    Forward. The graph is built here, fresh, every iteration.
  • opt.zero_grad(); loss.backward(); opt.step()★
    The three lines. Order matters; grads accumulate if you skip the first.
  • running += loss.item() * x.size(0)
    Log the float, not the tensor — keeping the tensor keeps its whole graph alive.
  • loss = loss / accum_steps
    Gradient accumulation: skip step() for N-1 iterations to fake a bigger batch.
  • model.eval()
    The other half of the pair. Forgetting it is why validation accuracy looks wrong.
  • with torch.inference_mode(): ...
    Wrap the whole eval pass. Roughly halves memory.
  • acc = (logits.argmax(1) == y).float().mean()
    Accuracy without a metrics library.
16Save, load, checkpointstate dicts
  • torch.save(model.state_dict(), "m.pt")★
    Save the weights, not the object. A pickled model breaks when your code moves.
  • model.load_state_dict(torch.load("m.pt"))★
    Build the architecture first, then pour the weights in.
  • torch.load(p, weights_only=True)default
    The default since 2.6. It blocks arbitrary code execution — pass False only for files you trust.
  • torch.load(p, map_location="cpu")★
    Loads a GPU checkpoint on a CPU-only machine.
  • torch.save({"model": ..., "opt": ..., "epoch": e}, p)
    A resumable checkpoint needs the optimizer state too.
  • model.load_state_dict(sd, strict=False)
    Returns the missing / unexpected keys. Useful for partial transfer.
  • keys prefixed "module."
    Saved from DataParallel/DDP. Strip the prefix or save model.module.state_dict().
17torch.compile & speedthe 2.x headline
  • model = torch.compile(model)★
    Traces to a graph and fuses kernels. Usually a one-line speedup; keep it after .to(dev).
  • torch.compile(model, mode="max-autotune")
    Slower to compile, faster to run. Also "reduce-overhead" for small models.
  • torch.compile(model, dynamic=True)
    Avoids recompiling for every new sequence length.
  • TORCH_LOGS="recompiles" python train.py
    Diagnose why compilation keeps re-triggering.
  • channels_last memory format
    model.to(memory_format=torch.channels_last) — real gains for CNNs on tensor cores.
  • with torch.profiler.profile(...) as p:
    Per-op timings, exportable to TensorBoard or Chrome trace.
  • graph breaks
    Prints, .item(), and data-dependent Python control flow all split the graph and cost most of the win.
18Scale out & shipmulti-GPU · export
  • torchrun --nproc_per_node=8 train.py★
    The launcher. It sets RANK, LOCAL_RANK, WORLD_SIZE for you.
  • model = DistributedDataParallel(model)★
    One process per GPU. Always prefer it to the older DataParallel.
  • DistributedSampler(ds)
    Required with DDP, and you must call set_epoch(e) or every epoch shuffles identically.
  • FSDP2 · fully_shard
    Shards parameters, grads and optimizer state — for models too big for one card.
  • ep = torch.export.export(model, (x,))modern
    The current capture path, ahead of TorchScript.
  • torch.onnx.export(model, (x,), "m.onnx", dynamo=True)
    ONNX for cross-runtime serving.
  • torch.jit.script · torch.jit.tracelegacy
    TorchScript still works but is no longer the recommended path — new code should use torch.export.
PART II

torchvision  ·  images

Datasets, augmentation, pretrained models and vision ops. Two things changed recently and most tutorials online have not caught up: transforms live in transforms.v2, and video decoding was removed in 0.26 — image decoding stays.

V1What's insidesix namespaces
  • torchvision.transforms.v2★
    Augmentation for images, boxes, masks and video.
  • torchvision.models★
    Pretrained classification, detection, segmentation, video backbones.
  • torchvision.datasets
    CIFAR, MNIST, ImageNet, COCO, plus ImageFolder.
  • torchvision.ops
    Boxes, NMS, RoI pooling, focal loss.
  • torchvision.io
    Image decode / encode. Video was removed here.
  • torchvision.tv_tensors
    Tensor subclasses that tell v2 transforms what they're holding.
  • torchvision.utils
    Grids, saving, and drawing boxes / masks / keypoints.
V2transforms v2 · the pipelinethe canonical order
  • from torchvision.transforms import v2★
    Import v2, not transforms. Same names, faster, and it handles boxes and masks.
  • v2.Compose([...])★
    Chain them. Order is not cosmetic — see the four lines below.
  • v2.ToImage()
    1. PIL / ndarray → an Image tv_tensor. Replaces the old ToTensor.
  • v2.RandomResizedCrop(224, antialias=True)
    2. Geometry and augmentation, while still cheap uint8.
  • v2.ToDtype(torch.float32, scale=True)
    3. scale=True maps [0,255] → [0,1]. Omit it and your images stay in the hundreds.
  • v2.Normalize(mean=[...], std=[...])
    4. Last. ImageNet stats: mean .485 .456 .406, std .229 .224 .225.
  • v2.Lambda(fn) · v2.RandomApply([...], p=0.3)
    Escape hatches for anything custom.
  • v2.ToTensor()retired
    Did convert and rescale in one opaque step. Use ToImage() + ToDtype(..., scale=True).
V3Transforms worth knowinggeometry · colour
  • v2.Resize(256) · v2.CenterCrop(224)★
    The standard eval pair. A single int resizes the shorter side.
  • v2.RandomHorizontalFlip(p=0.5)★
    Cheapest real augmentation there is. Wrong for text and digits.
  • v2.RandomRotation · RandomAffine · RandomPerspective
    Geometric jitter; each takes a fill for the new corners.
  • v2.ColorJitter(brightness=.4, contrast=.4)
    Photometric jitter. Skip it when colour is the signal.
  • v2.RandAugment() · TrivialAugmentWide() · AutoAugment()★
    Learned policies. TrivialAugmentWide is parameter-free and a strong default.
  • v2.RandomErasing(p=0.25)
    Cutout. Must come after ToDtype.
  • v2.CutMix(num_classes=n) · v2.MixUp(...)
    Batch-level: apply after the DataLoader or inside collate_fn, not per sample.
  • v2.functional.rotate(img, 30)
    Functional forms, for applying identical params to an image and its mask.
V4TVTensorsdetection & segmentation
  • from torchvision import tv_tensors
    Tensor subclasses. Zero copy — they only add a label so v2 can dispatch.
  • tv_tensors.Image(t) · tv_tensors.Video(t)
    Plain tensors are treated as images anyway; wrap for clarity.
  • tv_tensors.BoundingBoxes(b, format="XYXY", canvas_size=hw)★
    This is what makes a flip move the boxes too.
  • tv_tensors.Mask(m)
    Segmentation masks get nearest-neighbour interpolation automatically.
  • img, target = transform(img, target)★
    v2 transforms take arbitrary structures — dicts, tuples, lists — and transform them together.
  • v2.SanitizeBoundingBoxes()
    Drops boxes a crop pushed off-canvas, and the matching labels and masks. Put it last.
  • v2.ClampBoundingBoxes() · v2.ConvertBoundingBoxFormat(...)
    Clip to the image, or switch XYXY / XYWH / CXCYWH.
V5Datasetsbuilt in
  • datasets.ImageFolder(root, transform=tf)★
    One folder per class. The fastest way to train on your own images.
  • datasets.CIFAR10(root, train=True, download=True)★
    Same signature for MNIST, FashionMNIST, CIFAR100.
  • ds.classes · ds.class_to_idx
    Label names and the mapping — needed to read predictions back.
  • datasets.CocoDetection · VOCSegmentation · ImageNet
    Detection and segmentation sets; several need a manual download.
  • wrap_dataset_for_transforms_v2(ds)
    Makes a built-in detection dataset emit tv_tensor targets.
  • datasets.DatasetFolder(root, loader, extensions)
    ImageFolder generalised to any file type.
V6Models & weightsthe enum API
  • from torchvision.models import resnet50, ResNet50_Weights★
    Every architecture ships a matching *_Weights enum.
  • resnet50(weights=ResNet50_Weights.DEFAULT)★
    Best available checkpoint. Note it can change between releases — pin the explicit tag for reproducibility.
  • resnet50(weights=ResNet50_Weights.IMAGENET1K_V2)
    Explicit and stable. Strings work too: weights="IMAGENET1K_V2".
  • resnet50(weights=None)
    Random init — the architecture only.
  • preprocess = weights.transforms()★
    The exact preprocessing that checkpoint was trained with. Guessing it costs real accuracy.
  • weights.meta["categories"]
    Class-index → human label, shipped with the weights.
  • models.list_models() · models.get_model("resnet50", weights=...)
    Look up by string — handy for config-driven training.
  • model.fc = nn.Linear(model.fc.in_features, n)★
    Transfer learning. The head is .fc on ResNet, .classifier on VGG/EfficientNet, .heads on ViT.
  • resnet50(pretrained=True)removed
    Gone since 0.15. Every tutorial written before 2023 uses it — translate to weights=.
V7ops & utilsdetection plumbing
  • ops.nms(boxes, scores, iou_threshold)★
    Returns kept indices, sorted by score. Boxes must be XYXY.
  • ops.batched_nms(boxes, scores, idxs, thr)
    Per-class NMS — suppression never crosses categories.
  • ops.box_iou(a, b) · ops.generalized_box_iou
    Pairwise N×M IoU matrix.
  • ops.box_convert(b, "xywh", "xyxy") · ops.box_area
    XYXY is the format every torchvision utility expects.
  • ops.roi_align · ops.MultiScaleRoIAlign
    Crop features per box; the FPN version picks the level for you.
  • ops.sigmoid_focal_loss(logits, targets)
    RetinaNet's answer to dense-detection class imbalance.
  • ops.masks_to_boxes · ops.remove_small_boxes
    Segmentation → detection targets, and degenerate-box cleanup.
  • utils.make_grid(batch, nrow=8) · utils.save_image★
    Eyeball a batch in one line.
  • utils.draw_bounding_boxes · draw_segmentation_masks★
    Annotates a uint8 CHW tensor. Passing float images is the usual mistake.
V8Image I/Oand where video went
  • io.decode_image("cat.jpg")★
    File or byte tensor → uint8 CHW tensor. Format-agnostic.
  • io.read_image(p, mode=io.ImageReadMode.RGB)
    Force 3 channels — otherwise PNGs may arrive with an alpha band.
  • io.write_jpeg(t, p) · io.write_png(t, p)
    Encoders stay in torchvision.
  • io.decode_jpeg(data, device="cuda")
    nvJPEG GPU decode — worth it for large-batch pipelines.
  • io.read_video · io.write_video · io.VideoReaderremoved
    Deprecated in 0.22, removed in 0.26. Use torchcodec.decoders.VideoDecoder. The video datasets were migrated for you.
PART III

torchaudio  ·  sound

Read this first: since 2.9 torchaudio is in a declared maintenance phase. Its strengths — transforms, functional, models, pipelines, datasets, compliance.kaldi — are staying. Decoding and encoding moved out to TorchCodec, and torchaudio.io, torio and sox_effects were deleted. Anything on the web that streams audio through StreamReader is now broken code.

A1What survivedthe 2.9 cut
  • torchaudio.transforms★
    Feature extraction as nn.Modules. The heart of the package.
  • torchaudio.functional★
    The same operations, stateless.
  • torchaudio.pipelines★
    Bundled model + weights + the exact preprocessing.
  • torchaudio.models · .models.decoder
    Wav2Vec2, HuBERT, Conformer, Emformer RNN-T + CTC decoders.
  • torchaudio.datasets · .compliance.kaldi
    LibriSpeech and friends; Kaldi-compatible fbank / MFCC.
  • torchaudio.io · torio · StreamReader · apply_effects_fileremoved
    Deprecated in 2.8, deleted in 2.9. There is no shim.
  • lfilter · RNNTLoss · forced_align · overdrive
    Slated for removal, then kept after user pushback. Safe to use.
A2Load & savenow via TorchCodec
  • waveform, sr = torchaudio.load("a.wav")★
    Still works — but it is now an alias for load_with_torchcodec(), so you need torchcodec installed.
  • torchaudio.save("out.wav", waveform, sr)
    Likewise an alias for save_with_torchcodec().
  • from torchcodec.decoders import AudioDecoderpreferred
    The native path the team recommends porting to.
  • pip install torchcodec
    Separate package, not pulled in by torchaudio.
  • waveform.shape → (channel, time)★
    Channel-first, float32 in [-1, 1]. librosa hands you (time,) — that mismatch causes silent shape bugs.
  • waveform.mean(dim=0, keepdim=True)
    Downmix stereo to mono.
A3Spectrogram familywaveform → features
  • T.Spectrogram(n_fft=400, hop_length=None, power=2.0)★
    STFT magnitude. power=2 energy, 1 amplitude, None keeps it complex.
  • T.MelSpectrogram(sample_rate=16000, n_mels=128)★
    Literally Spectrogram then MelScale. The default input for most audio CNNs.
  • T.MFCC(sample_rate=16000, n_mfcc=40)★
    DCT of the log-mel. Classic ASR features; pass melkwargs= to tune the mel stage.
  • T.AmplitudeToDB(stype="power")
    Log scaling. Match stype to the power you used, or the dB range is wrong.
  • T.MelScale · T.InverseMelScale · T.LFCC
    The stages on their own, plus the linear-filterbank cousin of MFCC.
  • T.GriffinLim() · T.InverseSpectrogram()
    Back to audio. Griffin-Lim guesses the discarded phase.
  • spec.shape → (channel, freq, time)
    freq = n_fft // 2 + 1, or n_mels for a mel spectrogram.
A4Resample & augmentSpecAugment
  • T.Resample(orig_freq=44100, new_freq=16000)★
    Build it once and reuse — it precomputes a kernel, so constructing it per sample is slow.
  • T.FrequencyMasking(freq_mask_param=80)★
    SpecAugment: blank out frequency bands. Operates on spectrograms, not waveforms.
  • T.TimeMasking(time_mask_param=80)
    The time-axis counterpart. The pair is the standard ASR augmentation.
  • T.TimeStretch(rate, fixed_rate=True)
    Needs a complex spectrogram — set power=None upstream.
  • T.PitchShift · T.Fade · T.Vol
    Waveform-domain effects.
  • T.Vad() · T.SlidingWindowCmn() · T.ComputeDeltas()
    Voice activity trimming, cepstral mean norm, delta features.
  • nn.Sequential(resample, spec, masking).to(dev)★
    Transforms are Modules, so the whole feature pipeline runs on GPU and inside torch.compile.

  • F.resample(w, orig, new)
    One-shot version — fine for a single call, slow in a loop.
  • F.amplitude_to_DB · F.DB_to_amplitude
    Scale conversions without constructing a Module.
  • F.lfilter(w, a_coeffs, b_coeffs)
    Differentiable IIR filtering.
  • F.lowpass_biquad · highpass_biquad · bandpass_biquad
    Ready-made biquads for pre-emphasis and band limiting.
  • F.forced_align(log_probs, targets)
    CTC alignment — audio to transcript, frame by frame.
  • F.edit_distance(seq1, seq2)
    The building block for WER and CER.
A6Pipelines & modelspretrained speech

  • emission, _ = model(waveform)

    Beam search with an optional lexicon and language model.

train() ≠ grad onit only flips Dropout and BatchNorm; use no_grad to stop tracking
no_grad vs inference_modeboth stop recording; inference_mode is stricter and faster
view vs reshapeview needs contiguous memory, reshape copies when it must
cat vs stackcat keeps the rank, stack adds a dimension
losses take logitsCrossEntropyLoss and BCEWithLogitsLoss apply the softmax/sigmoid themselves
