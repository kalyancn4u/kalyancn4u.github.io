sktime cheat sheet

sktime is the scikit-learn of time series: one consistent fit/predict API across the whole time-series lifecycle — forecasting, classification, regression, clustering, annotation/anomaly detection — plus pipelines, tuning and reduction to tabular ML. It wraps statsmodels, StatsForecast, Prophet, Darts, ARIMA and deep-learning backends behind a shared interface. This sheet targets sktime 0.3x and focuses on forecasting.

Forecast

The core loop, and how sktime expects your data.

1Install & data format0.3x
  • pip install "sktime[all_extras]"★
    Base install is light; extras pull in soft deps (statsmodels, pmdarima, prophet, etc.). Install only what you use in prod.
  • y = pd.Series(values, index=pd.PeriodIndex(..., freq="M"))★
    A univariate series with a proper time index (PeriodIndex preferred; DatetimeIndex/RangeIndex also work).
  • # panel/multi-series: pd.DataFrame with a MultiIndex (instance, time)
    Hierarchical/multiple series use a MultiIndex; the same forecasters vectorize over instances.
  • from sktime.datasets import load_airline y = load_airline()
    Built-in datasets for experiments & docs examples.
2fit / predict / fhthe workflow
  • from sktime.forecasting.naive import NaiveForecaster f = NaiveForecaster(strategy="last") f.fit(y, fh=[1,2,3]); f.predict()★
    Fit, then predict the forecasting horizon. Always establish a naive baseline first.
  • from sktime.forecasting.base import ForecastingHorizon fh = ForecastingHorizon([1,2,3], is_relative=True)★
    fh can be ints (steps ahead) or an absolute index. Pass it to fit or predict.
  • f.fit(y, X=X_train, fh=fh); f.predict(X=X_future)
    Exogenous features via X — you must supply future X at predict time.
  • f.update(y_new) · f.predict()
    Stream new observations without a full refit (where the forecaster supports it).
3Forecaster zoopick a model
  • from sktime.forecasting.arima import AutoARIMA★
    Auto-tuned (S)ARIMA. Also StatsForecastAutoARIMA (the fast Nixtla backend).
  • from sktime.forecasting.exp_smoothing import ExponentialSmoothing from sktime.forecasting.ets import AutoETS
    Holt-Winters / ETS state-space models. ThetaForecaster is a strong, simple benchmark.
  • from sktime.forecasting.trend import PolynomialTrendForecaster from sktime.forecasting.fbprophet import Prophet
    Trend models and adapters to Prophet/Darts/statsforecast — all behind the same API.
  • f.get_params() · f.get_fitted_params()
    Inspect hyperparameters and fitted coefficients (sklearn-style).
4Probabilistic forecastsuncertainty
  • f.predict_interval(coverage=0.9)★
    Prediction intervals at a coverage level — returns lower/upper columns. Not every forecaster supports it.
  • f.predict_quantiles(alpha=[0.1, 0.5, 0.9])
    Arbitrary quantiles; predict_var() for variance, predict_proba() for a full distribution.
  • f.get_tag("capability:pred_int")
    Check a forecaster's capability tags before calling interval methods.

Compose

Chain transforms with a forecaster, or turn any sklearn regressor into a forecaster.

5Pipelines & transformspreprocessing
  • from sktime.forecasting.compose import TransformedTargetForecaster pipe = TransformedTargetForecaster([("detrend", Detrender()), ("fc", AutoARIMA())])★
    Transform the target (detrend/deseasonalize/boxcox), forecast, then invert — automatically.
  • from sktime.forecasting.compose import ForecastingPipeline
    Transforms the exogenous X before the forecaster (vs. target above). Use the right one for what you're transforming.
  • from sktime.transformations.series.detrend import Deseasonalizer, Detrender from sktime.transformations.series.boxcox import BoxCoxTransformer
    Series transformers compose like sklearn's. * operator builds pipelines: Detrender() * AutoARIMA().
  • from sktime.forecasting.compose import EnsembleForecaster
    Average several forecasters; StackingForecaster, AutoEnsembleForecaster for learned combinations.
6Reduction to sklearntabular ML
  • from sktime.forecasting.compose import make_reduction f = make_reduction(RandomForestRegressor(), window_length=12, strategy="recursive")★
    Turn any sklearn regressor into a forecaster via sliding windows — the bridge to gradient boosting / RF forecasting.
  • strategy="recursive" # or "direct", "dirrec", "multioutput"
    How multi-step ahead is produced: feed predictions back (recursive) vs one model per horizon (direct).
  • f.fit(y, fh=fh).predict()
    Once built, it's just another forecaster — same fit/predict, works in pipelines & tuning.

Evaluate & Tune

Backtest honestly with time-aware splits.

7Splitting & backtestingno leakage
  • from sktime.split import temporal_train_test_split y_train, y_test = temporal_train_test_split(y, test_size=24)★
    Chronological split — never shuffle time series. Test is the most recent tail.
  • from sktime.split import ExpandingWindowSplitter, SlidingWindowSplitter cv = ExpandingWindowSplitter(fh=[1,2,3], initial_window=48, step_length=12)★
    Rolling-origin backtest windows — the correct way to cross-validate a forecaster.
  • from sktime.forecasting.model_evaluation import evaluate evaluate(forecaster=f, y=y, cv=cv, scoring=MeanAbsolutePercentageError())★
    Run the whole backtest and get per-window scores in a DataFrame.
8Metrics & tuningpick the best
  • from sktime.performance_metrics.forecasting import ( MeanAbsolutePercentageError, MeanAbsoluteError, MeanSquaredError)★
    MAPE/sMAPE/MAE/RMSE and scaled variants (MASE). Callable like sklearn metrics.
  • from sktime.forecasting.model_selection import ForecastingGridSearchCV gscv = ForecastingGridSearchCV(f, cv=cv, param_grid={...})★
    Grid/random search that respects temporal CV. gscv.best_forecaster_, best_params_ after fit.
  • MeanAbsolutePercentageError(symmetric=True)
    sMAPE toggle; MeanAbsoluteScaledError for MASE (scale-free, comparable across series).

9Classification & moreother learning tasks
  • from sktime.classification.kernel_based import RocketClassifier clf.fit(X, y); clf.predict(X_test)★
    Time-series classification on panel data. Also TimeSeriesForestClassifier, KNeighborsTimeSeriesClassifier, HIVE-COTE.

    TS regression, clustering, and anomaly/changepoint detection — all share fit/predict.

    Time-series distances/kernels (DTW) power the distance-based classifiers & clusterers.
10Finding estimatorsthe registry
  • from sktime.registry import all_estimators all_estimators("forecaster", as_dataframe=True)★
    List every forecaster (or classifier, transformer...) available in your install.
  • all_estimators(filter_tags={"capability:pred_int": True})
    Filter by capability tags — e.g. only forecasters that produce prediction intervals or handle exogenous X.
  • from sktime.registry import all_tags
    Discover the tag vocabulary that describes what each estimator can do.

Gotchas

Time-series-specific traps.

!Common gotchasread before shipping
  • never shuffle / KFold a time series
    Use temporal_train_test_split and the window splitters — random splits leak the future into training.
  • index must carry a frequency
    A PeriodIndex/DatetimeIndex with a set freq avoids ambiguous-horizon errors; irregular gaps confuse many models.
  • exogenous X needs the future
    If you fit with X, you must provide X for the forecast horizon at predict time — you can't forecast without it.
  • soft dependencies
    Many estimators wrap other libraries; a missing one raises at import/fit. Install the specific extra, not always [all_extras].
  • not every forecaster does intervals
    Check get_tag("capability:pred_int") before calling predict_interval.
