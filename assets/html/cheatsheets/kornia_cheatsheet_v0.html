Kornia cheat sheet

Kornia is a differentiable computer-vision library built on PyTorch: classic CV ops (filtering, color, geometry, features) that run on the GPU, work in batches, and are differentiable — so they slot into a training graph and you can backprop through them. Think "OpenCV/skimage as tensor ops". Everything operates on (B, C, H, W) float tensors in [0,1]. Highlights: GPU augmentation that keeps images/masks/boxes/keypoints in sync, and deep local-feature matching (LoFTR). Targets Kornia 0.8.

Basics

The tensor contract, and getting images in/out.

1Install & tensor format0.8
  • pip install kornia # kornia[x] for extras import kornia as K, torch★
    Pure PyTorch dependency. Ops accept a device/dtype and stay on the GPU.
  • # the contract: (B, C, H, W) float tensor in [0, 1]★
    Batch-first, channels-second, normalized floats — unlike skimage (HWC) or OpenCV (HWC BGR).
  • t = K.utils.image_to_tensor(np_img).float() / 255. np_img = K.utils.tensor_to_image(t)★
    Convert HWC uint8 ↔ CHW float tensor (adds/removes batch dim, reorders axes).
  • t = K.io.load_image("img.jpg", K.io.ImageLoadType.RGB32, device="cuda")
    Load straight to a normalized tensor on a device.
2Color & conversionskornia.color
  • K.color.rgb_to_grayscale(t) · rgb_to_hsv(t) · rgb_to_lab(t)★
    Differentiable color-space transforms — and their inverses (hsv_to_rgb, ...).
  • K.color.rgb_to_bgr(t) # interop with OpenCV-origin data
    Swap channel order when your data came from cv2.
  • K.enhance.normalize(t, mean, std) · denormalize(...)
    ImageNet-style normalization as a tensor op (kept differentiable).

Augmentation

Batched, GPU, differentiable — and it transforms your labels too.

3GPU augmentationkornia.augmentation
  • import kornia.augmentation as Kaug aug = Kaug.RandomHorizontalFlip(p=0.5) out = aug(batch) # applied per-sample across the batch, on GPU★
    Augmentations are nn.Modules — run inside the training loop on the GPU (not per-image on CPU workers).
  • Kaug.RandomAffine(degrees=15) · RandomCrop(...) · ColorJitter(...) · RandomGaussianBlur(...)★
    The usual suite, all batched & random-per-sample.
  • aug(batch); params = aug._params # the sampled transform aug.inverse(out) # undo it (geometric augs)
    Kornia records the exact random params — you can invert geometric augmentations or replay them.
  • Kaug.RandomMixUp() · RandomCutMix() · RandomJigsaw()
    Batch-level augmentations too.
4AugmentationSequential (labels)keep labels in sync
  • seq = Kaug.AugmentationSequential( Kaug.RandomAffine(30), Kaug.RandomHorizontalFlip(), data_keys=["image", "mask", "bbox", "keypoints"])★
    The killer feature: geometric transforms apply consistently to the image and its masks, boxes & keypoints.
  • img_o, mask_o, bbox_o = seq(img, mask, bbox)★
    Pass each target in data_keys order; get them back transformed together.
  • seq.inverse(img_o, mask_o, bbox_o)
    Invert the whole pipeline — useful for test-time augmentation.

Process

Differentiable filtering and enhancement.

5Filters & edgeskornia.filters
  • K.filters.gaussian_blur2d(t, (5,5), (1.5,1.5))★
    Blur as a differentiable conv. Also box_blur, median_blur, motion_blur, bilateral_blur.
  • K.filters.sobel(t) · spatial_gradient(t) · laplacian(t, 3)★
    Gradient/edge operators returning tensors — can appear anywhere in a loss.
  • K.filters.canny(t) · K.filters.filter2d(t, kernel)★
    Differentiable Canny; apply an arbitrary custom kernel with filter2d.
6Enhance & morphologyadjust
  • K.enhance.adjust_brightness(t, 0.2) · adjust_contrast(...) · adjust_gamma(...)★
    Photometric adjustments as tensor ops; equalize, sharpness too.
  • K.morphology.dilation(t, kernel) · erosion · opening · closing · gradient
    Differentiable morphology (soft/hard) — the kernel is a tensor footprint.
  • K.contrib.distance_transform(t) · K.enhance.jpeg_codec_differentiable(...)
    Handy differentiable building blocks for custom pipelines.

Geometry

Kornia's core: warps you can differentiate through.

7Warps & transformskornia.geometry
  • K.geometry.transform.warp_perspective(t, M, (H, W))★
    Apply a 3×3 homography to a batch. warp_affine for 2×3 affine.
  • M = K.geometry.get_perspective_transform(src_pts, dst_pts)★
    Solve the transform from four point correspondences — then warp with it.
  • K.geometry.transform.resize(t, (256,256)) · rotate(t, angle) · center_crop(...)★
    Differentiable resize/rotate/crop/translate/scale — the tensor equivalents of PIL/skimage ops.
  • K.geometry.transform.remap(t, map_x, map_y) · K.geometry.depth...
    Arbitrary sampling grids; plus camera models, epipolar geometry, and depth utilities.
8Differentiable geometryoptimize a transform
  • M = torch.eye(3, requires_grad=True)★
    Make a transform a learnable parameter — because warps are differentiable, you can optimize alignment by gradient descent.
  • loss = ((warp_perspective(src, M, size) - tgt)**2).mean() loss.backward()★
    Image registration via SGD: minimize photometric error w.r.t. the homography — the canonical Kornia demo.
  • K.geometry.liegroup.So3 / Se3 · K.geometry.conversions.*
    Lie-group rotations & pose (angle-axis, quaternion, rotation-matrix conversions) for 3D vision.

Deep CV

Local features, matching, and loss functions.

9Features & matchingkornia.feature
  • matcher = K.feature.LoFTR(pretrained="outdoor") correspondences = matcher({"image0": g0, "image1": g1})★
    LoFTR detector-free deep matching — dense correspondences between two images, pretrained.
  • K.feature.DISK.from_pretrained(...) · K.feature.SIFTFeature() · KeyNet...
    Learned (DISK) & classic (SIFT/Harris) local features — keypoints + descriptors as tensors.
  • K.feature.match_snn(desc1, desc2) · LocalFeatureMatcher(...)
    Descriptor matching (mutual NN / ratio test) and end-to-end matcher modules.
  • K.geometry.ransac.RANSAC("homography")(pts1, pts2)
    Robustly fit a homography/fundamental matrix from noisy matches.
10Losses & modelskornia.losses
  • K.losses.ssim_loss(pred, tgt, 5) · psnr_loss(...) · total_variation(...)★
    Image-quality losses. Also focal_loss, dice_loss, tversky_loss for segmentation.
  • K.filters.get_gaussian_kernel2d(...) # build kernels as tensors
    Kernel factories when you need a custom differentiable filter.
  • K.contrib.FaceDetector() · kornia model zoo (segmentation, matching)
    Pretrained task models exposed as modules.
!Common gotchasread before shipping
  • (B, C, H, W) float [0,1]
    The universal input format. Passing HWC, uint8, or an unbatched tensor is the #1 error — use image_to_tensor and add the batch dim.
  • augment on the GPU, in the loop
    Kornia augmentation shines when the batch is already on the GPU — not as a per-sample CPU Dataset transform (that throws away the speedup).
  • use AugmentationSequential for labels
    Applying separate random augs to image and mask desynchronizes them. AugmentationSequential with data_keys keeps geometry consistent.
  • it's differentiable — mind the graph
    Ops keep gradients. Wrap in torch.no_grad() for pure preprocessing, or you'll accumulate an unwanted graph/memory.
