Pillow cheat sheet

Pillow (the maintained PIL fork) is the standard library for opening, converting, editing and saving images in Python — the layer under most ML data pipelines (a 🌐 datasets Image, a torchvision input, a matplotlib figure). Core object is Image; helpers live in ImageDraw, ImageFilter, ImageOps, ImageEnhance. This sheet targets Pillow 12.x.

Basics

Load a file, look at it, write it back.

1Open, inspect, saveI/O
  • pip install Pillow from PIL import Image★
    Import name is PIL, package is Pillow.
  • img = Image.open("photo.jpg")★
    Lazy: reads the header only. Pixels load on first use (or call img.load()). Use a with block or it holds the file handle.
  • img.size · img.width · img.height · img.mode · img.format★
    size = (w, h); mode = "RGB"/"L"/"RGBA"/...; format = "JPEG"/"PNG" (None once edited).
  • img.save("out.png") · img.save("out.jpg", quality=85, optimize=True)★
    Format inferred from the extension (or pass format=). quality/optimize for JPEG; img.show() to preview.
2Modes & convertcolor spaces
  • img.convert("RGB") · img.convert("L") # grayscale★
    Modes: "1" (bitmap), "L" (8-bit gray), "RGB", "RGBA" (alpha), "CMYK", "P" (palette).
  • rgb = img.convert("RGB") # before saving a PNG/RGBA as JPEG★
    JPEG can't hold alpha or palette — convert to RGB first or save errors.
  • img.getbands() · r, g, b = img.split() · Image.merge("RGB", (r,g,b))
    Access/recombine channels.

Transform

Geometry — almost all of these return a new image.

3Resize, thumbnail, cropsize
  • small = img.resize((256, 256), Image.Resampling.LANCZOS)★
    Returns a new image. LANCZOS = best quality for downscaling; BICUBIC/BILINEAR/NEAREST also available.
  • img.thumbnail((256, 256))★
    In-place and aspect-preserving — shrinks to fit within the box (never enlarges). The odd one out that mutates.
  • patch = img.crop((left, top, right, bottom))★
    Box is a (l, t, r, b) tuple in pixels. img.getbbox() finds the non-zero bounding box.
  • from PIL import ImageOps ImageOps.fit(img, (256,256)) # resize + center-crop to exact size★
    Fill a target size without distortion (crops overflow). ImageOps.pad to letterbox instead.
4Rotate, flip, fitorientation
  • img.rotate(45, expand=True, fillcolor="white")★
    Counter-clockwise degrees. expand=True grows the canvas so nothing is clipped.
  • img.transpose(Image.Transpose.FLIP_LEFT_RIGHT)★
    Fast 90° rotations & flips: FLIP_TOP_BOTTOM, ROTATE_90/180/270, TRANSPOSE.
  • ImageOps.exif_transpose(img)★
    Fix phone-photo orientation: applies the EXIF rotation tag so the image displays upright. Do this right after opening.

Create & Compose

Blank canvases, pasting, and drawing.

5New, paste, compositecombine images
  • canvas = Image.new("RGB", (800, 600), color=(255,255,255))★
    Blank image of a mode, size, and fill color (name, hex, or tuple).
  • canvas.paste(logo, (x, y))★
    In-place. Paste another image at a position.
  • canvas.paste(logo, (x, y), mask=logo)★
    Pass an RGBA image (or its alpha) as mask to paste with transparency.
  • Image.alpha_composite(base, overlay) · Image.blend(a, b, alpha=0.5)
    Proper alpha compositing (both RGBA) / linear cross-fade between two same-size images.
6Draw shapes & textImageDraw
  • from PIL import ImageDraw d = ImageDraw.Draw(img)★
    Create a draw context bound to the image; drawing mutates it in place.
  • d.rectangle([x0,y0,x1,y1], outline="red", width=3) d.ellipse(...) · d.line(...) · d.polygon(...)★
    Shapes take a bounding box / point list, plus fill/outline/width. Great for drawing detection boxes.
  • from PIL import ImageFont font = ImageFont.truetype("arial.ttf", 24) d.text((x, y), "label", fill="white", font=font)★
    Load a TTF for real fonts (default font is tiny). d.textbbox((x,y), text, font) measures it.

Adjust

Filters and tone/color adjustments.

7Filters & enhanceappearance
  • from PIL import ImageFilter img.filter(ImageFilter.GaussianBlur(radius=2))★
    Returns a filtered copy. Also SHARPEN, DETAIL, EDGE_ENHANCE, FIND_EDGES, UnsharpMask(), BoxBlur().
  • from PIL import ImageEnhance ImageEnhance.Contrast(img).enhance(1.4)★
    Factor >1 boosts, <1 reduces. Also Brightness, Color (saturation), Sharpness.
  • ImageOps.autocontrast(img) · ImageOps.grayscale(img) · ImageOps.invert(rgb)★
    One-shot tone ops. ImageOps.equalize, ImageOps.posterize for more.
  • img.point(lambda p: p * 1.2) # per-pixel LUT
    Fast per-channel lookup transform (e.g. gamma, thresholding).

Interop

Bridge to NumPy and handle animations.

8NumPy & pixelsarrays
  • import numpy as np arr = np.array(img) # (H, W, C) uint8, RGB★
    Pillow → NumPy. Note it's HWC RGB (torchvision wants CHW; cv2 uses BGR).
  • img = Image.fromarray(arr) # NumPy -> Pillow★
    Array must be uint8 (or match a mode). Scale floats to 0–255 first.
  • img.getpixel((x, y)) · img.putpixel((x, y), (255,0,0))
    Single-pixel access (slow in a loop — use NumPy for bulk edits).
  • img.getdata() · img.histogram()
    Flat pixel iterator and per-channel histogram.
9GIFs & multi-frameanimation
  • gif.n_frames · gif.seek(i) · gif.tell()★
    Navigate frames of a GIF/APNG/TIFF. seek moves to frame i.
  • from PIL import ImageSequence frames = [f.copy() for f in ImageSequence.Iterator(gif)]
    Iterate frames cleanly (.copy() because the iterator reuses the object).
  • frames[0].save("out.gif", save_all=True, append_images=frames[1:], duration=100, loop=0)★
    Write an animated GIF: save_all + append_images; duration ms/frame, loop=0 = forever.
!Common gotchasread before shipping
  • most methods return a NEW image
    img.resize(...)/crop/rotate/filter don't mutate — assign the result. thumbnail, paste, and ImageDraw are the in-place exceptions.
  • JPEG can't save RGBA/P
    convert("RGB") before saving a transparent/palette image as JPEG, or it raises.
  • open() is lazy & holds the file
    Use with Image.open(...) as im: im.load() (or work on a copy) so the handle is released — important in servers/loops.
  • EXIF orientation
    Phone photos may display sideways until you call ImageOps.exif_transpose — do it before resizing/cropping.
  • array layout: HWC RGB
    np.array(img) is HWC/RGB. Converting to torch needs CHW; from cv2 needs BGR↔RGB.
